# Python lab 1

---

## Условие задачи

### Задание 1

Для `x = 5` и `y = 5` выполняется `id(x) == id(y)`. Найти максимальный диапазон
целых чисел `[-M, N]`, для которого это равенство верно.

---

## Запуск программы

Для выполнения задания не нужны виртуальное окружение и дополнительные пакеты —
достаточно установленного Python 3.

### 1. Клонируйте репозиторий и перейдите в папку задания

Скопируйте и выполните команды в терминале:

```bash
git clone https://github.com/cinq-sur-cinq/task-1-int-optimization.git
cd task-1-int-optimization
```

### 2. Запустите программу

```bash
python int_optimization.py
```

Если команда `python` в вашей системе ссылается на Python 2 или не найдена,
используйте:

```bash
python3 int_optimization.py
```

После запуска программа выведет значения `M`, `N` и найденный диапазон.

---

Дополнительные зависимости отсутствуют: используется только стандартный Python.
